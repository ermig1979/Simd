Detailed Description

The SynetDynamicQuantizedInnerProduct16b class is a C++ wrapper of dynamic quantized inner product (matrix multiplication) for FP32/BF16 input, FP32/BF16/INT8 weight and FP32/BF16 output.

The class wraps C API functions SimdSynetDynamicQuantizedInnerProduct16bInit, SimdSynetDynamicQuantizedInnerProduct16bInternalBufferSize, SimdSynetDynamicQuantizedInnerProduct16bExternalBufferSize, SimdSynetDynamicQuantizedInnerProduct16bInfo, SimdSynetDynamicQuantizedInnerProduct16bSetParams and SimdSynetDynamicQuantizedInnerProduct16bForward. It dynamically quantizes matrix A to UINT8 and matrix B to INT8 (or uses an already quantized constant INT8 B), multiplies them and dequantizes the product. Optional FP32 bias and an activation function are applied after dequantization. The result is written as FP32 or BF16. Algorithm's details (bias = true): 

A[i, k] -> uA[i, k], scaleA[i], zeroA[i]
B[k, j] -> iB[k, j], scaleB[j]
for(i = 0; i < M; ++i)
    for(j = 0; j < N; ++j)
    {
        sum = 0;
        for(k = 0; k < K; ++k)
            sum += (uA[i, k] - zeroA[i]) * iB[k, j];
        val = sum * scaleA[i] * scaleB[j];
        C[i, j] = ConvertToTypeC(Activate(val + bias[j], activation, params));
    }

typeA and typeC can be SimdTensorData32f or SimdTensorData16b. typeB can be SimdTensorData32f or SimdTensorData8i when B is constant, and SimdTensorData32f or SimdTensorData16b when B is not constant. When avoidOverflow is SimdTrue, B is quantized to the narrowed range [-64; 63] instead of [-128; 127]. This flag is ignored when B is already quantized. If B is constant, it must be supplied to SetParams() and can be NULL in Forward(). Call Init() and, when B is constant, SetParams() before Forward(). Use Enable() to check that a context was created. The context is released by Clear() or by the destructor.

Using example: 

#include "Simd/SimdSynet.hpp"

int main()
{
    const size_t M = 4, N = 8, K = 16;
    std::vector<float> A(M * K), B(K * N), C(M * N, 0.0f), bias(N, 0.1f);
    for (size_t i = 0; i < A.size(); ++i)
        A[i] = float(i) * 0.01f;
    for (size_t i = 0; i < B.size(); ++i)
        B[i] = float(i) * 0.02f;

    Simd::SynetDynamicQuantizedInnerProduct16b innerProduct;
    innerProduct.Init(M, N, K, SimdTensorData32f, SimdTensorData32f, SimdTensorData32f,
        SimdTrue, SimdTrue, SimdConvolutionActivationIdentity, SimdTrue);
    if (innerProduct.Enable())
    {
        innerProduct.SetParams((const uint8_t*)B.data(), NULL, bias.data(), NULL);
        innerProduct.Forward((const uint8_t*)A.data(), NULL, NULL, (uint8_t*)C.data());
    }

    return 0;
}

Initializes (or re-initializes) a dynamic quantized inner-product context.

Creates an internal context with using of function SimdSynetDynamicQuantizedInnerProduct16bInit. The context is recreated only if matrix sizes, tensor types, the constant-B flag, the bias flag, the activation type or the overflow flag were changed.

Note
This function is a C++ wrapper for function SimdSynetDynamicQuantizedInnerProduct16bInit.
Parameters
[in]M- a height of A and C matrices.
[in]N- a width of B and C matrices.
[in]K- a width of A and height of B matrices.
[in]typeA- a type of A matrix. It can be SimdTensorData32f or SimdTensorData16b.
[in]typeB- a type of B matrix. It can be SimdTensorData32f, SimdTensorData16b or SimdTensorData8i. SimdTensorData8i indicates that B is already quantized and is valid only for constant B.
[in]typeC- a type of C matrix. It can be SimdTensorData32f or SimdTensorData16b.
[in]constB- a flag indicating that matrix B is constant and can be set once.
[in]bias- a flag to add bias to output matrix C.
[in]activation- an activation function type used after inner product.
[in]avoidOverflow- a flag to use narrowed ([-64; 63] instead of [-128; 127]) quantization range for B matrix. It is ignored if B is already quantized.

Sets weights, bias and activation parameters for dynamic quantized inner product.

This function must be called before Forward() if constB was SimdTrue during initialization. weight provides matrix B in FP32 or INT8 form with K*N elements. The implementation stores quantized constant B internally. Per-output-channel scales are used when B is already quantized and can be NULL otherwise. Bias is copied to an internal FP32 array; when bias is NULL, zeros are used. Activation parameters are copied or expanded to the internal FP32 array according to SimdConvolutionActivationType.

Note
This function is a C++ wrapper for function SimdSynetDynamicQuantizedInnerProduct16bSetParams.
Parameters
[in]weight- a pointer to matrix B weights of FP32 or INT8 type. The size of the array must be equal to K*N. Can be NULL only when B is not constant.
[in]scale- a pointer to per-output-channel FP32 scales of B matrix. The size of the array must be equal to N. Can be NULL if B is not quantized.
[in]bias- a pointer to FP32 bias array with N elements. Can be NULL.
[in]params- a pointer to FP32 parameters of activation function (see SimdConvolutionActivationType). Can be NULL when activation does not require parameters.

const uint8_t *  B,
uint8_t *  buf,

Performs dynamic quantized inner-product forward propagation.

The function quantizes A (and non-constant B) at runtime, computes the matrix product with INT8 weights and per-channel scales, dequantizes the product, optionally adds bias and applies activation according to parameters stored by Init() and SetParams(). The result is written as FP32 or BF16. If B is constant, it can be NULL when it was set by SetParams(). The buf argument can be NULL (it causes usage of internal buffer).

Note
This function is a C++ wrapper for function SimdSynetDynamicQuantizedInnerProduct16bForward.
Parameters
[in]A- a pointer to A matrix of FP32 or BF16 type with size M*K. Actual element type is defined by typeA in initialization.
[in]B- a pointer to B matrix of FP32 or BF16 type with size K*N. Can be NULL if B is constant.
[out]buf- a pointer to external temporary byte buffer. Can be NULL.
[out]C- a pointer to output C matrix of FP32 or BF16 type with size M*N. Actual element type is defined by typeC in initialization.
