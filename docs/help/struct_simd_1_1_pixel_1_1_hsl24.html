Detailed Description

24-bit HSL pixel.

Stores hue, saturation, lightness as three consecutive bytes. This is the element type of a View::Hsl24 image, including the output of Simd::BgrToHsl. Each component is an 8-bit value in [0, 255], in the same order as the C description of SimdPixelFormatHsl24. There is no constructor from Bgr24; convert a whole image with Simd::BgrToHsl and then read pixels with View::At<Pixel::Hsl24> or Hsl24::At.

Creates a gray 24-bit HSL pixel.

Hue and saturation are set to 0. Only the lightness channel receives gray. Hsl24() is black.

Gets a constant reference to the HSL pixel at (col, row).

Requires view.format == View::Hsl24 and then returns Simd::At. col is the x coordinate and row is the y coordinate; both must lie inside the view. Use this after Simd::BgrToHsl, or use view.At<Pixel::Hsl24>(x, y).
